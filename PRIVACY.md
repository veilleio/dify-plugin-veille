# Privacy policy

This plugin is published by Veille (https://www.veille.io).

## What the plugin sends

When a tool runs, the plugin sends the value to check (an email, domain, IP address, phone number, VAT number or IBAN) or the currencies for exchange rates to the Veille API at `https://api.veille.io`, with your API key in the `x-api-key` header. When you save the API key in Dify, the plugin checks it with one request that costs no credits.

The plugin calls no other host.

## What the plugin stores

The plugin stores nothing. It keeps no logs, files or caches. Dify stores the API key you enter, as it does for every plugin credential.

## What Veille does with the data

Veille processes requests to return results and to count credits on your account. See the Veille privacy policy: https://www.veille.io/privacy
